# Design reference

Reference material for building the site. **Nothing here is published.**

- `storyboards/`: screen recordings, GIFs or frame sequences showing scroll-driven or animated behaviour. Name each after its interaction ID in the build spec, e.g. `INT-03-hotspot-open.mp4`.
- `exports/`: screenshots of Figma frames, PDFs or anything else useful for checking the build against the designs.

Final artwork goes in `public/illustrations/`, not here.
